# Mhastar Probity College

Official website and backend API for Mhastar Probity College - A co-educational private secondary school in Sango Ota, Ogun State, Nigeria.

**Motto:** Towards Academic & Moral Excellence

## 🏫 About

Mhastar Probity College is committed to academic excellence and moral development in a serene learning environment. We offer comprehensive Junior and Senior Secondary School programmes with both day and boarding options.

## 📂 Project Structure

```
mhastar-probity-college/
├── mp-frontend/          # Next.js website
└── mp-backend/           # Backend API (coming soon)
```

## 🚀 Frontend

The website is built with:
- **Next.js 16.4.6** - React framework
- **TypeScript** - Type safety
- **Tailwind CSS 4.3.3** - Styling
- **Lucide React** - Icons

### Features
- ✅ 8 complete pages (Home, About, Academics, Boarding, Facilities, Admissions, Gallery, Contact)
- ✅ Navy blue and gold color scheme
- ✅ Fully responsive design
- ✅ Component-based architecture
- ✅ SEO optimized
- ✅ Production ready

### Development

```bash
cd mp-frontend
npm install
npm run dev
```

Visit http://localhost:3000

### Build

```bash
cd mp-frontend
npm run build
npm start
```
